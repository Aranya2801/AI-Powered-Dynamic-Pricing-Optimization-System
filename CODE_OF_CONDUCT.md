# Code of Conduct

We pledge to make participation in this project a harassment-free experience for everyone.

**Positive behavior:** welcoming language, respecting differing viewpoints, gracefully accepting feedback.
**Unacceptable behavior:** harassment, trolling, personal attacks, publishing others' private info.

Report violations by opening a GitHub issue or emailing conduct@dynamic-pricing.ai.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/) v2.1.
